# Gurpreet Gill — V3 Personal Brand Website

This is a static HTML/CSS/JS website designed as a personal brand and action-focused platform — not a CV.

## Main positioning
- Encourage people with ideas to start building.
- Help 0→1 founders turn early ideas into real businesses and scale.
- Help established businesses explore new markets, sectors and countries.
- Invite leadership teams to bring Gurpreet in for speaking and team sessions.
- Leave room to add other speakers/leaders later.

## Files
- `index.html` — website
- `styles.css` — brand/design system
- `script.js` — mobile navigation
- `gurpreet-gill.png` — supplied photograph

## Before launch
1. Replace the LinkedIn links if a different profile should be used.
2. Add the final email address when ready.
3. Connect the chosen domain through GitHub Pages, Vercel or another static host.
4. Add analytics and a privacy/cookie notice if analytics or other tracking is introduced.

## Suggested domain setup
Use `www.yourdomain.com` as the primary address and redirect the root domain to it, or follow the hosting provider's recommended apex + www setup.
